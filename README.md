# Retail Performance Dashboard - Excel & Power BI

## Main Steps
1. Data collection, cleaning and modeling with Power Query & Excel
2. Interactive Excel dashboard creation (pivot tables, slicers, VBA macros)
3. Migration and optimization to Power BI
4. Advanced visualizations with dynamic KPIs, temporal/category filters
5. Two-page interactive dashboard development

## Objectives & KPIs
- **Total Cost • Net Profit • Total Customers**
- **Monthly Trends • Category Breakdown**
- **Top/Bottom 5 Products/Brands/Cities • Customer Satisfaction**

## Key Findings
- **Fashion** category drives maximum profitability
- **Online channel** shows +20% average basket vs store
- Top 3 cities represent 65% net profit
- Clear identification of underperforming products for optimization

# Pilotage Performance Retail - Excel & Power BI

## Étapes principales
1. Collecte, nettoyage et modélisation des données avec Power Query & Excel
2. Création dashboard Excel interactif (TCD, segments, macros VBA)
3. Migration et optimisation vers Power BI
4. Visualisations avancées avec KPI dynamiques et filtres temporels/catégoriels
5. Développement d'un dashboard interactif sur 2 pages

## Objectifs & KPIs
- **Coût total • Profit net • Total clients**
- **Tendances mensuelles • Répartition catégories**
- **Top/Bottom 5 produits/marques/villes • Satisfaction client**

## Résultats clés
- Catégorie **Mode** génère la rentabilité maximale
- Canal **Online** : +20% panier moyen vs magasin
- Top 3 villes = 65% profit net
- Identification claire des produits sous-performants à optimiser
